落地要点

内容是现有的，材质是新的。

macOS

材质
26+ 用 NSGlassEffectView；12–15 回退 NSVisualEffectView 毛玻璃。
范围
玻璃工具栏、侧栏、内容浮卡外壳、菜单栏面板、悬浮球与详情弹层；浮卡内保持实色。
不变
浮卡内的分段标签、平台分组、账户卡与额度行全部沿用现状；页头标题与说明移入玻璃工具栏。
回退
低于 26 只降级材质，布局与尺寸不变。

Windows

材质
主窗口 Mica；菜单栏面板与详情弹层 Acrylic；系统禁用透明效果时回落实色。
范围
32px 标题栏、Mica 侧栏、Fluent 2 的 8 / 4 圆角、28px 页标题、36px 导航与 3×16 指示条；字体 Segoe UI Variable。
不变
总览仍用现有分段标签、平台分组、账户卡与额度行结构，不重排内容。
回退
Windows 10 或 Mica 不可用时走 Fluent 2 实色，不保留半透明。
保留 mac 玻璃工具栏 + 实色浮卡 不改总览布局 不改账户卡与额度行 不改菜单栏面板结构 不改悬浮球几何与交互

确认后先做 Rust 材质层，再按现有 class 替换背景、边框与字体；总览与面板的 DOM 结构不动。Windows 的 Mica / Acrylic 仍需 Windows 11 实机复核。
